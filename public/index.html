Как пользоваться сервисом

Этот сервис помогает заполнять карточки товаров для маркетплейса Prom.ua, генерируя текстовые поля с помощью ИИ на основе ваших данных.

  1. Подготовьте исходный файл.
    Поддерживается только формат XLSX.
    Первая строка должна содержать названия колонок. Данные начинаются со второй строки. Файл должен содержать таблицу с товарами, где первая строка — названия колонок.
  2. Загрузите файл.
    Нажмите «Выберите файл» и укажите ваш XLSX. Имя файла появится рядом. Затем нажмите «Загрузить файл».
  3. Сопоставьте поля шаблона с колонками вашего файла.
    В левой панели перечислены поля шаблона Prom.ua, в правой — колонки из вашего файла. Для каждого поля шаблона выберите соответствующую колонку исходника, если она есть.
  4. Отметьте поля для генерации.
    Рядом с названием поля шаблона есть чекбокс. Если его отметить, значение этого поля будет создано ИИ, а не взято из файла. Если поле одновременно сопоставлено и отмечено для генерации, значение из файла будет использовано как контекст для улучшения генерации, а в итог попадёт сгенерированный текст.
  5. Отметьте колонки, которые должны использоваться как контекст.
    В правой панели рядом с каждой колонкой есть чекбокс. Отметьте те колонки, данные из которых вы хотите передать ИИ для генерации. Они будут добавлены в промпт.
  6. Добавьте дополнительные инструкции (по желанию).
    В поле «Дополнительные инструкции для ИИ» можно написать пожелания, например: «Делай описания в деловом стиле», «Избегай сложных терминов». Этот текст попадёт в каждый запрос.
  7. Запустите обработку.
    Нажмите «Обработать». Обработка может занять время — количество запросов к ИИ зависит от числа строк (по одному на каждую строку) и лимитов частоты. После завершения автоматически скачается файл с результатом.

Важно:

  • Красные поля и сообщения означают, что обязательные данные не заполнены. Исправьте их до отправки.
  • Для выполнения генерации обязательно должны быть входные данные.
  • Обработка идёт по строкам. Если какая-то строка не удалась после 3 попыток, она будет пропущена, остальные попадут в результат.
